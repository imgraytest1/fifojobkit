# FIFO Job Kit

Free tools to get FIFO work in Australia: tickets, real pay, jobs, resume, savings goals and wellbeing.
Live at https://fifojobkit.com. By Awesome Alchemy.

- `index.html`: the kit (built from the claude.ai artifact source)
- `404.html`: poster QR landing page (/quokka, /spiral, /jobs, /rsea, /wasafety)
- `sw.js` + `manifest.webmanifest`: offline use and "Add to home screen"
